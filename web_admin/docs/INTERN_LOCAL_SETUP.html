CoolClean PHP Local Setup

A beginner-friendly guide for restoring the Laravel source and connecting it to the existing local MySQL database.

RequirementsSourceEnvironmentDatabaseRunLogin flowProblems
Important: CoolClean uses the existing COOLCLEANDB_PHP database and existing uppercase tables. Do not run php artisan migrate.

This source package does not contain passwords, database credentials, Git history, installed dependencies, or private database data.

1. Requirements

  • Windows 10 or 11
  • Laragon with PHP 8.3 or newer
  • MySQL 8
  • Composer
  • Visual Studio Code or another editor
  • The existing CoolClean database or an authorized SQL backup

Check the tools in a Laragon terminal:

php -v
composer --version
mysql --version

2. Extract and install the source

  1. Extract coolclean-php-intern-source.zip.
  2. Place it somewhere such as C:\laragon\www\coolclean-php.
  3. Open the folder containing artisan and composer.json.
  4. Install the PHP dependencies:
composer install

Composer recreates vendor. That generated folder is intentionally excluded from the ZIP.

3. Create the local environment

Copy the safe example configuration and generate a unique Laravel key:

Copy-Item .env.example .env
php artisan key:generate
Never share or commit .env. It can contain database passwords and service keys.

4. Prepare the existing database

Option A — It already exists locally

Start MySQL in Laragon, connect to it, and verify the database:

USE COOLCLEANDB_PHP;
SHOW TABLES;

SYSTEM_SETTINGS

Option B — Restore an authorized backup

Use only a trainer-approved and sanitized SQL backup. Open MySQL:

mysql -u root -p

Create and select the database:

CREATE DATABASE COOLCLEANDB_PHP
CHARACTER SET utf8mb4
COLLATE utf8mb4_unicode_ci;

USE COOLCLEANDB_PHP;
SOURCE C:/path/to/approved-coolclean.sql;
SHOW TABLES;

If the local root password is blank, press Enter when requested.

Configure Laravel

Update the database section in .env:

APP_NAME=CoolClean
APP_ENV=local
APP_DEBUG=true
APP_URL=http://127.0.0.1:8000

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=COOLCLEANDB_PHP
DB_USERNAME=root
DB_PASSWORD=

SESSION_DRIVER=file
CACHE_STORE=file
QUEUE_CONNECTION=sync

Leave DB_PASSWORD blank only when the local MySQL account genuinely has no password.

5. Test the connection

Clear cached settings:

php artisan optimize:clear

Start Tinker:

php artisan tinker

Then test the uppercase USERS table:

App\Models\User::count();
exit
If Laravel displays a number, the database connection works.

6. Start CoolClean

php artisan serve

7. Understand the login flow

resources/views/auth/login.blade.php │ POST /login ▼ routes/web.php ▼ app/Http/Controllers/Auth/LoginController.php ▼ app/Models/User.php ▼ COOLCLEANDB_PHP.USERS ▼ Dashboard redirect OR login error

Also open docs/intern-laravel-guide.html for the illustrated Laravel lesson.

8. Project rules

  1. Do not run php artisan migrate.
  2. Do not create replacement lowercase tables.
  3. Keep the existing uppercase model mappings.
  4. Do not commit .env, SQL backups, passwords, API keys, logs, or user data.
  5. Back up data before changing production records.
  6. Test locally before deployment.

9. Common problems

ProblemWhat to check
Access denied for userCheck MySQL username and password in .env.
Unknown databaseCreate or restore COOLCLEANDB_PHP.
Table ... doesn't existConfirm the correct database and uppercase tables. Do not run migrations.
Old environment valuesRun php artisan optimize:clear.
Port 8000 is busyRun php artisan serve --port=8001.
CSS is missingClear Laravel cache, restart the server, and press Ctrl + F5.

10. First intern exercise

Trace one login attempt through:

  1. resources/views/auth/login.blade.php
  2. routes/web.php
  3. app/Http/Controllers/Auth/LoginController.php
  4. app/Models/User.php

Explain what data enters each layer, what validation happens, which database column is queried, and how success or failure returns to the browser.
